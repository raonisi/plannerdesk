# PR-122 — 공식 출처 확인 기준

**Cursor/자동화:** 외부 확인 **미실행** → 운영자 기입 전 **「확인 필요」** 유지. **최신·정확 단정 금지.**

---

| 항목 | 우선 확인 출처 | 비고 |
| --- | --- | --- |
| 보험사명 | 보험사 공식 홈페이지 | 공식 표기 우선 |
| 청구안내 | 공식 청구안내·고객센터 | URL 개편 빈번 |
| 청구서류 | 공식 청구서류·약관 안내 | 상품·상황별 차이 |
| 팩스번호 | 공식 고객센터·청구안내 | 지점·상품별 차이 |
| 헬프데스크 | 공식 안내·설계사 전용 경로 | 내부 확인 병행 |
| 앱/홈페이지 | 공식 앱스토어·홈페이지 | 비공식 링크 금지 |
| 전산 | 설계사 포털 공식 안내 | HTTPS·리다이렉트 |
| 공시/약관 | 공식 공시실 | `termsUrl`, disclosure |
| 지식 | `sourceUrl`·내부 검수 | `sourceCheckedAt` |
| 제3자 참고 (보험학교 등) | **보험사 공식과 병행** | PR119 #9 |

---

## 점검 시 기록 (점검표)

- 확인일
- 출처 URL 또는 문서명 (**secret 없음**)
- 확인자
- 다음 주기 (월/분기)

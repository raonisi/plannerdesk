## 분류 규칙

- 한 행에 **주 유형 1개** (복합이면 비고에 부유형)
- visibility·권한·secret은 **별도 유형**으로 표기 (다른 유형에 묻지 않음)
- 확인되지 않은 데이터는 **데이터 오류로 단정하지 않음** → 보류 + 정보 부족

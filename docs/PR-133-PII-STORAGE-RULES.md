# PR-133 — 변경 이력 저장 금지 항목

운영·감사 목적의 **모든** 이력 레이어(PR133-A 메타데이터 표시, PR133-B 이벤트 테이블)에 적용.

## 금지

고객명, 주민번호, 연락처, 주소, 계약번호, 보험증권 번호, 병력·진단 원문, 상담 원문, 계좌·결제정보, 신분증/증권 이미지, **secret**, **token**, API key, **env**, 내부 서버 경로, stack trace 원문.

## 허용 (요약·metadata)

- entityType / entityId (admin only)
- actionType, changedAt
- 변경자 내부 ID **마스킹 표시** (···suffix)
- 검수·게시 상태 라벨
- 민감정보 제거된 필드 요약 (예: “청구 URL 변경됨” — URL 전체는 PR133-B에서 redaction 정책 후)

## 변경 사유 (reason) 예시

- 공식 출처 확인 완료
- 오탈자 수정
- 링크 만료·대체 URL 반영
- 검수 요청·보류

## 금지 사유 예시

- 고객 상담 전문 인용
- “무조건 지급” 등 판단 단정

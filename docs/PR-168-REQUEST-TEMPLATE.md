# PR-168 — Data Correction Request Template

| 항목 | 작성 기준 |
| --- | --- |
| 요청 유형 | 보험사 / 청구서류 / 업무 링크 / 지식 아카이브 / public 검색 |
| 오류 등급 | Critical / High / Medium / Low |
| 대상 화면 | route명 또는 화면명 |
| 대상 데이터 | 보험사명·문서 유형·링크 유형 등 |
| 오류 요약 | 고객정보 없는 비식별 요약 |
| 공식 출처 후보 | 공식 링크 또는 공식 문서명 |
| 확인 상태 | 미확인 / 확인 필요 / 공식 확인 완료 |
| public 보류 필요 여부 | 필요 / 불필요 / 판단 보류 |
| 후속 PR 후보 | Hotfix / Data Correction / UX Polish 등 |
| 금지 정보 확인 | PII·secret·지급 확정 없음 |

저장 위치는 PR168-A에서 정하지 않는다. inbox·티켓·PR 본문에 비식별 요약만 기록한다.

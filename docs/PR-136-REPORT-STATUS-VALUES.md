# PR-136 — 관리자 리포트 상태값 기준

| 상태 | 의미 | 처리 기준 |
| --- | --- | --- |
| **정상** | 검수 완료 또는 운영 기준 충족 | 유지·다음 점검 일정 기록 |
| **확인 필요** | 공식 출처·최신성·권한·링크 상태 확인 필요 | 운영자 확인 후 재분류 |
| **수정 필요** | 오류·누락·만료 링크·문구 위험 | 데이터 PR 또는 콘텐츠 PR |
| **보류** | 근거 부족·public 부적합 | 비공개·draft 유지 |
| **비공개** | public 미노출 유지 필요 | published 전환 금지 |
| **긴급** | Critical/High 리스크 | 배포 보류·rollback 검토 |
| **정보 부족** | 현 자료로 판단 불가 | 근거·스크린샷·출처 추가 |

## 우선순위

1. **긴급** (Critical/High: visibility·권한·secret·AA safety·운영 DB)
2. **수정 필요** (청구·링크·핵심 route)
3. **확인 필요**
4. **보류 / 비공개**
5. **정상**

## 금지

- 확인 필요 링크를 **정상**으로 단정
- 미검수 데이터를 **정상**으로 분류
- 고객정보·원문을 리포트 셀에 기입

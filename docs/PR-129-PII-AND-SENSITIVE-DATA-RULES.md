# PR-129 — 이슈 기록 시 개인정보·고객정보 보호 기준

PlannerDesk 운영 이슈 Registry는 **문서 기반**이며, **고객 PII·상담 원문 저장소가 아니다.**

**연계:** [PR-121-SENSITIVE-DATA-RULES.md](./PR-121-SENSITIVE-DATA-RULES.md) (피드백 동일 원칙)

---

## 기록 금지

- 고객명
- 주민등록번호·생년월일 조합으로 특정 가능한 정보
- 연락처·주소
- 계약번호·보험증권 번호
- 병력 상세·진단명 원문
- 상담 원문 전체·녹취·채팅 전문
- 가족관계 상세
- 계좌정보·보험료 결제정보
- 신분증·보험증권 이미지 원문
- 비밀번호·토큰·API 키·`.env` 값
- allowlist 원문·운영 DB 덤프

---

## 허용

- 화면명·route·기능명
- 오류 유형·HTTP 상태(요약)
- 재현 단계 **요약** (민감정보 없이)
- 민감정보 **제거된** 이슈 요약
- 내부 테스트용 **가상** 데이터
- metadata 중심 상태 (심각도·PR 번호·재현 여부)

---

## 처리 규칙

| 상황 | 조치 |
| --- | --- |
| 제보에 PII 포함 | **저장 전 삭제·익명 요약**만 Registry 기입 |
| 재현에 고객 데이터 필요 | 스테이징·가상 데이터만 사용 |
| 스크린샷에 PII | 마스킹 후 첨부; 원본 공유 금지 |
| AA·audit 로그 | **metadata만** — PR126 기준 유지 |

---

## 위반 시

1. 해당 행 **즉시 편집** (PII 제거)
2. 심각도 **High** 이상 검토 (유출 범위 확인)
3. secret·토큰 의심 시 **Critical** + 운영 중단 절차

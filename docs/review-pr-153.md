* **Codex 제한검수 필요 여부:** **필수 (Required)**. 대고객 소통을 위한 공지 문안이 담긴 패키지이므로, 법무적 리스크(지급 확정 등)나 운영 기획의 뉘앙스가 실무진(Codex)의 의도와 일치하는지 문구의 교차 검토가 요구됩니다.

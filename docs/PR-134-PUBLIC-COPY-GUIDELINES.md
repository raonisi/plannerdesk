# PR-134 — public 링크 안내 문구

코드: `PUBLIC_LINK_SAFETY_COPY`, `WORK_LINK_COPY` in `lib/directory/`

## 사용 중 (좋은 예)

- 공식 안내 페이지로 이동합니다.
- 접근 권한이 필요한 전산 링크일 수 있습니다.
- 공식 출처 확인 후 공개됩니다.
- 공식 확인 후 업데이트 예정 (missing slot)

## 금지

최신 링크 확정 · 무조건 여기로 · 100% 정확 · 검수 없이 공개 · DB/env/token · stack trace

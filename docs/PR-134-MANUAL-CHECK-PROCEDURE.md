# PR-134 — 링크 상태 수동 점검 절차

1. [점검표](./PR-134-LINK-CHECK-SHEET.md) 또는 admin 보험사 수정 화면에서 대상 확인
2. 링크 유형 분류 (전산/청구/공시 등)
3. 브라우저에서 **소량·수동**으로 URL 열기 (자동 스크립트·대량 요청 금지)
4. 공식 도메인·보험사 안내와 대조
5. 전산: 로그인 필요 여부만 기록 (접속 성공 여부만으로 정상 판정 금지)
6. 상태 하나 선택: 정상 / 확인 필요 / 수정 필요 / 보류 / 비공개 / 검수 대기
7. 수정 필요 → 근거·스크린샷(PII 제거)과 함께 **별도 데이터 PR** (PR124 등)
8. 확인 필요·보류 → public 정상 표시 금지
9. `updatedAt`·변경 사유는 [PR-133](./PR-133-CHANGE-HISTORY-OPS.md) 기준
10. OPS 이슈 필요 시 [PR-129](./PR-129-OPERATIONAL-ISSUES-OPS.md) 등록

## 금지

- curl/Playwright 일괄 스캔
- 운영 DB 직접 URL 일괄 UPDATE
- 공식 출처 없이 “최신·정상” 단정

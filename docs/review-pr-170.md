## 2. 핵심 요약

* **잘된 점 3가지:**
  1. **결제정보(PCI-DSS) 비저장 원칙 확립:** 카드번호, 결제토큰, 계좌정보를 자체 DB에 절대 저장하지 않고 모든 처리를 PG(Payment Gateway)에 위임하도록 아키텍처 강제 조항을 두었습니다.

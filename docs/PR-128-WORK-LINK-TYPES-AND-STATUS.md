# PR-128 — 업무 링크 유형·상태값 기준

코드 상수: `lib/directory/work-links.ts` · UI: `InsurerPrimaryWorkLinks`

## 유형 (public 표시)

| 유형 | 라벨 | 표시 조건 |
| --- | --- | --- |
| 전산 | 전산 바로가기 / 설계사 포털 | URL 있을 때만 링크; 없으면 `공식 확인 후 업데이트 예정` |
| 청구안내 | 청구안내 보기 | `claimPageUrl` 또는 패널 |
| 홈페이지 | 공식 홈페이지 | `officialWebsiteUrl` |
| 약관·공시 | 약관 확인 / 공시실 확인 | URL 또는 허브 안내 |
| 헬프데스크 | 헬프데스크·고객센터 전화 | 번호 있을 때 `tel:` |

## 상태 (내부 → public)

| 상태 | public 처리 |
| --- | --- |
| draft / unpublished | **미노출** (guard) |
| needs_review | 노출 가능 + `공식 확인 진행 중` 힌트 |
| verified | 노출 + 과도한 “확정” 문구 없음 |
| 링크 없음 | `공식 확인 후 업데이트 예정` (정상 단정 금지) |
| 공시 partial | `공식 공시 경로 확인 후 업데이트됩니다` |

## 그룹핑

| 그룹 | 포함 |
| --- | --- |
| 청구 업무 | 청구안내, 필요서류 |
| 전산 업무 | 전산·포털, 브라우저 권장 |
| 공식 정보 | 홈페이지, 약관/공시, 공시 허브 |
| 지원·문의 | 고객센터, 헬프데스크 |

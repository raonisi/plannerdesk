# Knowledge Archive IA Plan
# 지식 아카이브 IA 설계

## 1. 목적

- 지식 아카이브는 보험설계사가 반복해서 묻는 실무 질문을 검수된 문서로 축적하는 공간이다.
- 단순 FAQ가 아니라 검색 가능한 실무 지식 저장소다.
- 공식 출처, 검수 상태, 최종 수정일, 안전 경계를 함께 관리한다.
- 커뮤니티와 AI 답변 보조의 기반이 된다.
- 현재 PR에서는 구현하지 않고 IA만 설계한다.

## 2. 제품 내 위치

PlannerDesk 확장 구조에서 지식 아카이브는 다음 위치를 가진다.

- 실무 포털: 보험사 디렉토리, 청구서류, 공시/약관, 고객 안내문
- 지식 아카이브: 반복 질문과 실무 기준 축적
- 검증 설계사 커뮤니티: Q&A, 노하우, 업무 팁 공유
- AI 답변 보조: 검수된 지식 아카이브 기반 답변 초안 생성
- 관리자 검수 시스템: 공개 여부, 출처, 검수 상태 관리

## 3. 핵심 원칙

- 검수되지 않은 문서는 공식 지식처럼 노출하지 않는다.
- 공식 출처가 필요한 문서는 `sourceUrl` 또는 `sourceNote`를 가져야 한다.
- 보험금 지급 여부를 판단하지 않는다.
- 보험금 지급 금액을 산정하지 않는다.
- 손해사정 업무처럼 보이는 답변을 금지한다.
- 의료 진단을 해석하지 않는다.
- 고객 개인정보와 의료자료를 처리하지 않는다.
- 커뮤니티 글은 관리자 검수 후에만 지식 아카이브로 승격한다.
- AI 답변 보조는 `verified` 문서만 참조하는 것을 원칙으로 한다.

## 5. 문서 타입

- `FAQ`: 반복 질문에 대한 빠른 기준 안내 (예: 전산 접속 오류 1차 점검)
- `실무 기준`: 상황별 처리 기준과 예외 조건 정리 (예: 청구 경로 안내 기준)
- `안내문 샘플`: 고객 응대 문구 초안 제공 (예: 약관 확인 요청 문구)
- `체크리스트`: 누락 방지 점검 항목 제공 (예: 고지 전 확인 항목)
- `링크 가이드`: 공식 링크 진입 경로와 변경 시 대응 가이드 (예: 공시 링크 확인 순서)
- `안전 경계`: 금지 표현과 비허용 범위 명시 (예: 보험금 판단 금지)
- `운영 가이드`: 검수/갱신/보관 운영 절차 정리 (예: 문서 상태 전환 기준)

## 6. 지식 문서 후보 필드

중요:

- 아래는 실제 모델이 아니라 IA 단계의 후보 필드다.
- 이번 PR에서는 DB 모델/타입을 구현하지 않는다.

후보 필드:

- `title`
- `question`
- `shortAnswer`
- `body`
- `category`
- `tags`
- `sourceType`
- `officialSourceUrl`
- `sourceNote`
- `verificationStatus`
- `riskLevel`
- `aiUsable`
- `aiRestrictionNote`
- `lastReviewedAt`
- `reviewedBy`
- `relatedLinks`
- `forbiddenClaims`
- `safeCopy`
- `createdAt`
- `updatedAt`

## 7. 검수 상태 후보

실제 enum 생성 없이, IA 후보 상태만 정의한다.

- `draft`: 작성 중, 공개 불가
- `needs_review`: 검수 대기 또는 근거 보완 필요, 공식 지식으로 취급 불가
- `verified`: 검수 완료, 공개/AI 참조 후보
- `archived`: 운영상 비활성 보관 상태
- `rejected`: 기준 미충족으로 채택 불가

## 8. 위험도 후보

실제 enum 생성 없이, IA 후보 위험도만 정의한다.

- `low`: 단순 사용법, 링크 안내
- `medium`: 공식 출처 확인 필요
- `high`: 고객 응대·고지·청구 관련 주의 필요
- `blocked`: 보험금 판단, 손해사정, 의료 진단 해석, 개인정보·의료자료 처리 요청

## 9. AI 참조 기준

- AI 답변 보조는 `verified` 문서만 참조한다.
- `needs_review` 문서는 AI 참조 대상에서 제외한다.
- 커뮤니티 원문은 AI가 직접 참조하지 않는다.
- 커뮤니티 우수글은 관리자 검수 후 지식 아카이브로 승격된 경우에만 참조 가능하다.
- AI 답변은 최종 판단이 아니라 설계사용 초안이다.
- AI 답변에는 근거 문서와 안전 문구가 필요하다.
- 보험금 지급 여부, 지급 금액, 손해사정, 의료 진단 해석은 답변하지 않는다.

## 12. 커뮤니티 연결 원칙

- 커뮤니티 글은 바로 지식 아카이브가 아니다.
- 우수 답변 후보는 관리자 검수 후 아카이브로 승격한다.
- 고객 개인정보, 의료자료, 특정 고객 사례가 포함된 글은 승격할 수 없다.
- 출처가 불명확한 개인 경험담은 공식 지식으로 등록하지 않는다.
- 커뮤니티 글을 AI 답변 보조가 직접 참조하지 않는다.
